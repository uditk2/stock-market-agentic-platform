# Issue 026 - UI polish pass for home workflow clarity

## Problem
Current home layout feels rough/inconsistent and does not guide user attention clearly after setup.

## Scope
- Improve spacing, hierarchy, labels, and action grouping in home workspace.
- Improve readability for status badges and empty states.
- Ensure layout works cleanly on common desktop widths.

## Acceptance Criteria
- Home screen has clearer visual hierarchy for status, actions, recommendations, and detail panel.
- Key controls are grouped and labeled consistently.
- No regressions in onboarding or recommendation interactions.
- Desktop tests pass.

## Out of Scope
- Full design system replacement.
- Dark mode implementation.
